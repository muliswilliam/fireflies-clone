# Clone the Fireflies.ai app - technical challenge

# Overview

As part of our engineering candidate evaluation process, we are interested in assessing your ability to think critically, solve complex problems, and demonstrate your coding skills. For this assessment, you will be tasked with creating a simplified replica of the Fireflies product. This exercise will help us understand your approach to software development, your creativity, and your ability to work with existing tools and frameworks.

## Task Objective

Your goal is to create a basic version of the Fireflies application. This should include core functionalities:

- Meeting Recording: Simulate the ability to record a meeting (this can be a placeholder function)
- Transcription: Provide a basic text output of what was "discussed" in the meeting
- Summary & Action Items: Provide the summary and key takeaways
- User Interface: Create a simple user interface that allows users to interact with the application

## Requirements

- Use any coding language
  - Typescript - preferred
  - Go
  - etc
- The application should be functional and demonstrate your understanding of software development principles
- You may use libraries or frameworks to speed up development, but please document any third-party tools you use. We heavily encourage you to use AI tools like Replit.ai, Cursor, Claude Code, Lovable.dev and others like Supabase
- Include a README file that explains how to set up and run your application, as well as any assumptions you made during development

## Submission Instructions

- Please submit your completed project as
  1. A GitHub repository
  2. A link to the working app
  3. A brief document describing what you did
- Ensure that your code is pushed to the repository before the submission deadline
- Include any additional notes or comments that you feel are necessary for us to understand your thought process

## Deadline

Please submit your completed assessment within 48 hours of receiving this document. We encourage you to spend less than 10 hours in total on it. Please estimate time spent as well

We look forward to reviewing your submission and seeing your approach to this project!
